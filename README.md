# Bilgisayar Uykusu Simülatörü

## Giris

Bu proje, modern bilgisayar sistemlerinin en temel ve en ihmal edilmis ozelligini ele almaktadir: UYKU. Evet, bilgisayariniz yorgundur. Bu yazilim, bilgisayarinizin uyku durumunu bilimsel, akademik ve son derece ciddi bir sekilde simule eder.

## Neden Bu Proje?

Cunku her bilgisayar bir noktada dinlenmeye ihtiyac duyar. Bu simulator, kullanici girdisini alir, rastgele bir sure bekler (uyku), ve sonra "zzzz..." diye cevap verir. Bu, bilgisayar bilimlerinin zirvesidir.

## Kurulum

```bash
pip install -r requirements.txt  # hicbir sey yok aslinda
python uykucu.py
```

## Kullanim

Programi calistirin, bir sey yazin, bekleyin. Bekleyin. Daha fazla bekleyin. Sonra cevap gelir.
